# Frozen 185-answer scoring inputs

Release: `cleareval-benchmark-20261103-v1`.

| File | Role |
| --- | --- |
| `inputs.json.gz` | Original question/answer text, parsed steps, reference steps and evidence anchors, tissue tier, generation configuration |
| `verified_checks.json.gz` | Frozen V5 operation checks for fast replay and regression comparison |
| `adjudications.json` | Eight user-reviewed decisions tied to exact source excerpts and branch IDs |
| `previous_components.json.gz` | Previously determined CCE components reused by the complete scorer |
| `run_receipt.json` | Portable input hash, source snapshot hash and original-answer preservation record |

The source input snapshot SHA-256 is preserved in `run_receipt.json`.
The portable snapshot removes machine-specific paths and redundant previous scores,
and embeds the tissue tier and generation configuration previously retrieved from
separate files. Questions, answers, execution steps and reference steps are not
rewritten. Every answer retains its original SHA-256.

Run `python OEQ_run_grading_new.py` from the repository root. The default invokes
the packaged source-bound V5 verifier and reapplies the reviewed decisions.
`--cached-checks` consumes the frozen checks directly. The remaining CCE inputs
are the declared historical component values and current explicit completion
policy, rather than newly sampled model judgments.

Review excerpts and scoring records are evaluator inputs. They are not inputs
for generating benchmark answers. No new answers are generated by this release.
