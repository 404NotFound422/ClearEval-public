# glm4.7-thinking 透明时间提取修复与人工校验报告

## 修复内容

1. **问题根因**
   - `glm4.7-thinking` 的回复采用“分节式”protocol：章节标题含核心关键词但无时间，子步骤含时间但无核心关键词。
   - 原 `extract_clearing_time.py` 只从“自身含核心关键词”的行提取时间，导致大量子步骤时间被漏掉。
   - 另外，glm4.7-thinking 的同一子步骤常同时写 `"for X hour"` 和 `"(Temperature: ..., Time: X hour)"`，原脚本会重复计数。

2. **修复方案**（仅修改 `extract_clearing_time.py`）
   - 新增“核心章节”模式：当一行被识别为核心步骤但本身无时间，且看起来像章节标题时，进入子步骤收集模式。
   - 在章节模式下，对后续编号/缩进子步骤提取时间，即使子步骤自身不含核心关键词。
   - 子步骤必须通过“核心上下文”检查：包含核心试剂（methanol/DCM/DBE 等）或核心动作（dehydrat/bleach/delipid/RI matching 等）。
   - 对常规清洗、固定、染色、抗体孵育等非透明化子步骤进行过滤；但允许 "for imaging"、"mount" 等作为 RI 匹配后的用途描述。
   - 在 `parse_time_to_hours` 中优先解析 `"(Temperature: ..., Time: X unit)"`，避免与行首 `"for X hour"` 重复计数。

3. **修复效果**
   - `glm4.7-thinking` 成功提取数：133/253 → 185/253
   - 缺失率：47.43% → 26.92%
   - 平均透明时间：113.64 h → 88.33 h
   - 中位数：52.00 h → 36.00 h

## 人工校验方法

- 选取 12 个具有代表性的 `question_id`，覆盖 12 类组织中的主要类型。
- 逐行阅读 `glm4.7-thinking` 的 `model_response`，按以下规则人工累加透明化核心流程时间：
  - 计入：脱水、脱脂/脱钙、漂白、脱色、水合/再水化、折射率匹配等。
  - 排除：固定、通透化、封闭、一抗/二抗孵育、洗涤、染色、核染色、成像、封片等。
  - `overnight` 按 8 h 计；范围取平均值；`repeat twice` 等重复说明不额外加倍（因脚本未解析）。
- 将人工值与脚本提取值对比，记录差异及原因。

- 对于格式规范、不重复描述的分节式 protocol，`glm4.7-thinking` 的脚本提取值与人工阅读值**完全一致**（6/6，差异 0%）。
