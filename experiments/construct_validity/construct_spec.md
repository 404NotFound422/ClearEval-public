# 研究与测量合同（开发版 cv-dev-20260929-v1）

本文件固定本轮工程语义；科学要求与证据待领域审阅，尚未批准为正式测量合同。被测对象是根据科学目标、样本和信号约束，提出具有适用证据的透明与成像方案。实验前文献支持、专家认可、真实湿实验结果分别记录；本轮不输出实验成功概率。

任务 A：科学问题到标记及透明方案；任务 B：给定信号到透明方案。当前开发根任务为 A：3、79、122，B：145、157、165。六题均已被检查，不能作为独立保留集，也不代表真实应用分布。

每项要求保存稳定 ID、必要性、类型、证据范围和旧版父项。q165 的跨样本拼接、跨突触解释、尺度条件已拆开；DiI/DiD、EGFP/tdTomato、GFP/YFP 的科学保留依据分别核验。试剂、持续条件、时长、RI 介质、平衡/保存分别列项。必要性仍须科学审定。

| 类型 | 测量对象 | 不能推断为 |
|---|---|---|
| TEXT | 文本写出的解释边界或设计约束 | 已实现的信号保留 |
| COMPLETENESS | 要求的操作或字段是否写出 | 详细配方必然正确 |
| SCIENTIFIC | 目标身份、兼容性、尺度和方法依据 | 方法名称或模型常识即为已核实支持 |

状态为 SATISFIED（本项获支持）、VIOLATED（明确矛盾的操作或错误身份/符合性声明）、UNDER_SPECIFIED（必要成分或细节未提供，包括明确省略）、UNRESOLVED（科学依据、适用性或来源冲突未决）。明确省略按当前开发约定记信息不足，此边界待专家确认。

所有同时必要项采用合取：任一明确违反则整体违反；全部满足才整体满足；否则保留信息不足/证据未决及完整逐项向量。可选项不进入默认必要合取。替代路线采用完整分支析取，不跨互斥分支拼接。程序支持显式 all/any 公式，尚不自动推断条件适用性；裁判不得自行免除必要项。

分别保存模型 proposed_status 和经检查的 effective_status。无来源、无关来源、仅引用保留声明不能建立科学满足。证据范围检查仅检查初步关联，不能证明原文支持结论；语义判断仍待独立参照。作者编写的范围可能不完整，必须同时测合法替代接受和弃判覆盖。

关系抽取以 labels[]、steps[]、ri[] 保存同荧光团多目标、分支、原文位置和未知字段。抽取与原文裁判分开，抽取结果不充当独立真值。尚未全面展开抗体宿主、同型、克隆等细节字段，也未完成独立语义验证。

时间诊断要求显式阶段依赖和单位；重复次数独立记录，并行按最长路径计算。未明示小时数的 overnight 保持未知。参考只匹配明确样本层级与时间范围，不选最快子类。新辅助公式两侧均用 τ=0.20×参考中位数，历史非对称行为保留；数值不解释为概率。

RI 辅助诊断要求实际介质和显式数值；方法名称不能补成匹配液。RI 接近不能单独证明透明效果或兼容性。时间/RI 诊断尚未合成科学主分数。

超时、格式、截断、依赖缺失等技术状态与科学状态分开。技术恢复不根据科学答案是否理想决定。正式冻结尚需领域审阅、合法替代路线、来源分组保留集、独立初评及正式模型清单。
