# 指标、分母与统计约定

开发阶段只报告实际计数、耗时、结构错误、预设控制一致性和重复性。没有独立参照时，科学准确率、误放行、误拒、接受风险及其区间均记不可估计；缺少分母返回 null，不返回 0。

| 指标 | 分子 / 分母 |
|---|---|
| 误放行 | 参照为违反而评价为满足 / 参照为违反 |
| 误拒 | 参照为满足而评价为违反 / 参照为满足 |
| 接受风险 | 评价为满足但参照为违反 / 评价为满足且有独立二元参照 |
| 明确判定覆盖 | 满足或违反 / 计划评价条目 |
| 未决或信息不足 | 对应状态数 / 计划评价条目 |
| 技术失败 | 对应故障 / 计划请求；另列未提交和依赖阻塞 |
| 抽取精确率/召回率 | 正确关系 / 输出关系或独立参照关系，待独立事实标注 |

要求级与完整方案级分开。技术失败保留在计划分母，同时报告有返回结果子集。独立参照未决和评阅分歧单列，不强行当负例。risk_counts 接口计算给定参照的基础计数，不认证参照来源。

固定答案重复评价按逐要求向量比较，保留所有配对翻转、完整 JSON 差异及经验熵 H=-Σp log₂p。三次裁判不是三个独立科学题目；汇总不变不表示理由或分项不变。极少重复的经验熵不解释为总体噪声估计。

正式比较固定任务、完整方案、证据和独立参照。统计入口计算相同条目的 B−A 差，再按独立来源组等权平均；自助法整组重采样，默认 5,000 次、种子 20260929，百分位 95% 区间。无独立参照/分组保留集不算区间；少于 10 个独立组只报告描述值。10 组是保守报告规则，不是功效保证。正式版本仍需冻结组权重、主次指标和多重比较规则。

样本量设计参考：n 个独立、同分布的已确认负例中误放行为 0 时，单侧 95% 上界为 1−0.05^(1/n)。要低于 5% 至少需 59 个独立负例；低于 1% 至少需 299 个。不能以同题变体、重复裁判和多模型输出直接充当独立样本。这是设计诊断，不是本轮结果。

控制期望由助手编写，与模型输入分离，匹配率不称专家验证准确率。新版提示、要求和文献同时改变，前后试跑差异不能单独归因；只对同一模型输出施加/移除检查的离线差异，称检查的机械影响。


细粒度事件匹配（fine_grained_metrics.py v1）

来源绑定按冻结完整答案SHA与每字段连续引用校验，仅报告给定引用位置绑定率；不代表语义准确率或完整内容召回。模型提出的15事实/34引用位置不进入独立科学gold分母。

严格关键错误事件以(task_id,answer_id,candidate_id,requirement_id,entity_id,condition_scope,polarity,cause_id)完整匹配；正确标签但错候选、错对象或错因不计TP，分别留下FP与FN。optional违反不作为关键错误；必要性也须正确。预测U/信息不足/技术失败保留在预先计划分母及已确认关键错误召回分母。独立参照本身U/信息不足单列，不作为确认FP或科学负例。

至少一个已评估候选满足与全部已评估候选满足分开报告。GLOBAL必要状态与局部守卫共同参与这两个终点；额外answer限制保留在contract_status。没有完整推荐角色参照时，所有推荐候选有效性保持null。不得从非空matched列表推断整个回答全部建议有效。

参考真实性由上游评阅制度提供，指标函数只验证调用者声明与冻结计划的一致性、不认证专家或科学。按来源组报告macro；多个模型答案和变体不自动变成独立研究来源。工程控制值和文本算术参考单独报告，不宣称科学准确率。
