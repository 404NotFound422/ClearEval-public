固定原 SR/SP 的 MPNET、阈值 0.7 和原始输出；新编码器或新覆盖定义单列版本。保留参数完整性、Cor 的四项尺度、EGES 函数与 CCE/IA/HV 权重。定性 Cor 的职责修订要明确 rubric 版本。采用同一题干、全文、需求与来源比较；保存答案、参考清单、prompt、知识表、模型 digest 和程序版本。

实际本地别名 `qwen3.8:27b-q8_0-local` 与已保存运行元数据中的 `qwen35 / 27.3B / Q8_0` 分别登记；别名不是公开基础模型版本的证明。不采用 Llama 作为评价器。没有真实可用的第二家族时，该部分保持待运行。

新人工仍为一位专家，5 份开发＋15 份留出，步骤和提取共用同一份核查；每份记录实际检查字段及工时。完整参考建设按路线和适用范围单独登记。旧确认材料已暴露，不能纳入新的独立留出。

## 2. 各问题的最小假设和失败条件

| 问题 | 最小对照 | 主要观测 | 可证伪条件 |
|---|---|---|---|
| P01 范围查询 | 旧单键/范围查询；知识行顺序置换 | 返回 row_id、范围依据、原值 | 调换行序改变值；错误范围仍给相同证据 |
| P02 输入适用性 | 固定事实，逐一移除无关/必要信息 | 哪个通道变化、是否误传播缺值 | 缺克隆使已证实关系失效；删除必要关系仍照给分 |
| P03 实例覆盖 | 编码器、操作实例、阶段关系逐步加入 | 核查覆盖边的正确率、必要操作遗漏 | 中文分数回升，但一实例继续虚增被删除的操作 |
| P04 截断句 | 完整句/合法跨句指代/无对象残句 | 能否建立来源支持的操作实例 | 拒绝合法指代，或从参考给残句补对象 |
| P05a 阶段 | 原步骤与标题绑定/忽略绑定 | 同一数字是否计入正确范围 | 字段数值正确但仍计错阶段 |
| P05b 累计 | 关系正确/按普通增量处理 | 每项贡献及总时间 | 累计量重复加和，或忽略累计变化 |
| P05c 分支 | 区间/可选/互斥分别编码 | 可实现分支集合、分支内时间 | 20/32 h 被当成未报告的 26 h 路线 |
| P06 Cor 职责 | 2×2 同输入 prompt 对照 | 越界理由、null、已知错误、档位 | 完整率上升来自无依据给分或不再识别明显错误 |
| P07 删除与不变性 | 编辑前/编辑后全文同配置 | 预声明判项的成对变化 | 有效必要删除仍不响应；等义表达造成判项改变 |
| P08 多参考 | 冻结全相容集及事前选定子集 | 每版分数、切换、必要性前提 | 逐步骤混合版本；按结果选最有利参考集 |
| P09 稳定性 | 固定中间事实重判/全文重新评价 | 首个差异层、NA 与判项翻转 | 把缓存或确定性重算算成模型重复 |
| P10 联合 | 一致场景内比较，再同步抽样 | 支配、平均逐题 HV、场景翻转 | 从不同场景拼分；模型各自抽不同题 |

这些是事前预期；实际有效反例、无响应和未运行项都保留。不能为了全部通过而把测试前提、阈值或参考集随结果更改。

## 3. Cor 原因定位：避免又一次同时改很多东西

固定 5 份开发答案、参考上下文、模型和解码设置，比较下面四格。每格保留相同的原档位和输出字段。

| | 笼统“证据不足则 null”要求 | 每个判项列出必要证据要求 |
|---|---|---|
| 旧定量/定性职责混合 | C00 | C01 |
| 按用户要求划清 Cor 与 EGES | C10 | C11 |

每份输出按分项标记：是否可评分、引用是否支持理由、是否越界作数值有效性裁判、已知结构/逻辑错误是否仍识别。对原条件完全相同的成功返回可复用；不能仅因为答案 ID 相同就复用不同 prompt 或参考上下文的结果。

先完成一轮最多 5×4=20 个判分请求。它用于因果方向诊断，不足以估计随机方差。若要先固定共同事实输入，额外提取最多 5 次，总计最多 25 次；如果保持原整合输出格式而不独立提取，则不能再声称已隔离提取层。两种实现应在执行前选择一种，不能结果出来后混算。

解释差异：若仅改变职责就减少越界理由，支持职责问题；若仅细化必要证据就消除不相关 null，支持依赖问题；若两者组合才有效，报告交互。无论哪种情况，都须核对新增数值的证据，不能以完整率单项判断成功。

## 4. 让提取改进与覆盖改进可分辨

先使用已暴露材料整理一个紧凑事实结构，只提取影响评分的操作实例、阶段、标签关系、时间关系和来源。不要要求专家给整篇答案补完整可执行协议图。可复用当前来源文档、标签处理、时间账本、分项公式和已有评分结果。

用户后续明确提出统一英文测试，优先次序据此调整；具体说明见 [英译与时间补充](ENGLISH_AND_TIME_zh.md)。P03 先比较原文＋MPNET 与忠实英文全文＋同一 MPNET，固定 0.7，隔离语言因素。已有步骤英译探针不能替代全文流程验证。之后的比较使用同一经开发确认的事实：

1. 固定英译输入，先保留 MPNET；若残余召回仍不足，再比较一个预先选定多语言嵌入，校准只用 5 份开发材料的已核边与负例。
2. 固定候选集，比较按文本最大相似度与按操作实例身份判定。
3. 固定实例集合，加入来源支持的阶段关系；检查 C04 的前段/后段混淆。

这不是三组主 CCE 配置。原 `sr/sp` 是固定基线；候选输出 `semantic_coverage`、逐边依据、局部未知和错误类型。阈值、k、术语规范化表必须在留出之前冻结。E5/BGE/Qwen 不同模型不能共用未经验证的余弦阈值。

## 5. 与 E1–E6 的具体接合

**E1/E3。** 同一专家核查 20 份自然答案：初始条件、相容路线、必要操作匹配、关键关系与计算输入。机器分数和模型身份隐藏，显示原文和候选证据。自动提取与只忠实修正已核字段后的原 EGES 成对计算；不修正答案的科学选择，不替答案补缺参数。报告按答案计数与按字段计数，避免把同一答案几十个字段当作独立样本。

**E2。** 首先用 3 个有来源的基础案例，每例 3 个主变体：编号等义、真实步骤合并、必要功能删除，共 12 个全文。它们用于验证 P03/P04/P07，不是完成全部 E2 的充分条件。再补必要参数删除及有证据冲突；最后完成 6–8 个完整替代路线对，区分同方法版本与跨方法路线。对照双方均按编辑后的全文重新解析、提取、选参考和评分；固定配置后真正完成配对才计入。

**E4。** 完整管线新重复与固定事实后的 judge 重复分开。最小诊断可选 3 份不同失败类型答案，2 家族×3 次真实重复。它小于任务包默认上限，只能支持小样本诊断。报告真实请求矩阵及各层波动，不沿用“缓存重放=新重复”的口径。

**E5。** 首先展示全队列分项和缺失原因，再展示固定模型的共同题集。在预设的连贯场景下计算均值 CCE、逐题 IA/HV、支配矩阵；阈值适配与原阈值敏感性分开。少量题目可以精确枚举；来源块只有一个时不报告来源级总体置信区间。

**E6。** 继续保持既有样本量假设、数据模板和分析入口的计划状态。软件和核查实验不能替代真实湿实验结果，也无需等待 E6 才研究上述计算问题。

## 6. 请求量按实际接口计数

令每个全文的提取需要 e 次请求、Cor 需要 j 次请求，则一次完整评价成本为 e+j。以下采用 e=j=1 作明确例子；原整合调用若只需一次，按真实矩阵重新计数。相同输入和配置的成功单元可以复用，失败重试另计。

上述成本以评分输入已经准备好为前提。统一英文方案下，非英文新全文的翻译请求另加；冻结译文后的重复不重复计翻译，包含重新翻译的全流程重复则需计入。因此下表未包含尚未固定数量的新增全文翻译请求，不是该新增方案的最终总预算。

| 候选批次 | 例示上限，尚未执行 | 用途 |
|---|---:|---|
| Cor 2×2 开发，5 份共同提取 | 5＋20＝25 | 分离职责与证据要求因素 |
| E2 第一组，3 基础×4 全文 | 12×2＝24 | 先验证三种最核心变换 |
| 每基础再加参数删除、冲突 | 6×2＝12 | 补齐另外两类控制 |
| 6–8 对完整替代路线 | 12–16 全文×2＝24–32 | 基线有精确缓存时扣除可复用单元 |

全表相加只是无复用、双请求接口的成本上界 151–159，不是现在必须运行或已获授权的预算。先做诊断开发并作去留判断，未解决具体反例时不扩到全部留出。执行前按所选接口和精确缓存形成真实待运行矩阵，重新确定总量。当前已用 438/438，研究交付不增加该账本。

## 7. 什么结果才值得写进论文

应报告具体减少了哪种错误、还有哪些反例，并给受控成对差异与局部核查依据。来源字符串能定位、schema 能通过、所有值有限，都是工程属性；只有经核查的关系、步骤和取值才支持评分保真。

完整率、正确性、随机重复性和跨设置稳健性分别展示。15 份留出限制了结论精度，不把它包装成高置信度通用性能。新覆盖模块若没有超越仅翻译/仅编码器的对照，其贡献就应收缩为工程适配；若范围查询即可解决的错误，不包装成语义推理突破。
