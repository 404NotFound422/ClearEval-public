# Qwen 全文英译：8 次真实请求与问题定位

本批已完成用户批准的 8/8 次本地 Qwen 请求，全部正常返回并成功解析 JSON，无重试。两份原始答案分别生成基线、改编号、合并、删除四种全文，共形成 6 个真实配对。原编码器、0.7 阈值、SR/SP 公式和方法版本选择规则均未改动。总账为 446/446；本批生成等待时间合计约 605 秒，输出 13,457 tokens，均在批准的截止时间内完成。

主要结果是：英文基线的 SR 改善得到复现，但“每份全文独立重译”的流程出现新的格式扰动敏感性。C07 仅改编号后，重新翻译产生不同措辞，SR 从 4/7 降到 0。离线交叉对照已经把本例的直接原因定位到译文措辞及阈值跨越；不能把它简单归因于 JSON 提取失败，也不能据此宣称同一输入的随机重复稳定性变差。

**真实输入、来源与设置。** C04 来自 GPT-5.2-thinking 的 q2 答案；C07 来自 Claude-sonnet-4.6 的 q248 答案。两份均为此前已暴露的开发材料，8 个变体不是 8 个独立自然答案，更不是新增留出集。翻译模型使用本地别名 `qwen3.8:27b-q8_0-local`，digest 与冻结配置一致；服务 0.40.3，保存的底层模型元数据为 qwen35、27.3B、Q8_0。温度 0、关闭 thinking、最大输出 8192 tokens、上下文 98304，输出原生 JSON schema 的 `english_text`。

每次输入完整问题和编辑后的完整答案，未提供参考 protocol 或助手英文稿。C04 在两个既有完整 iDISCO+ 版本中按最高 SR、同版 SP、固定顺序选择；C07 使用已有完整 FDISCO 全脑参考。6 个配对均未切换参考，固定基线参考的差值与自适应选择一致。[输入矩阵](matrix.json) · [模型现场记录](runtime_preflight.json) · [逐份来源与实际结果](RESULTS_PER_TRANSLATION.csv)。

参考原件继续复用已有发布者附件：[iDISCO+ 补充材料](https://ars.els-cdn.com/content/image/1-s2.0-S0092867416305554-mmc8.pdf)及[FDISCO 原论文](https://doi.org/10.1126/sciadv.aau8355)。参考步骤、版本、原件本地路径和全部候选分数均保存在[评分结果](scoring/results.json)。这些是既有条件适用参考，不将本轮运行冒称新的专家适用性认证。

| 全文条件 | C04：SR / SP（步数） | C07：SR / SP（步数） |

| Qwen 英译基线 | 0.3333 / 0.3077（39） | 0.5714 / 0.0526（19） |

| 合并后重新英译 | 0.3333 / 0.3158（38） | 0.5714 / 0.1111（18） |
| 删除后重新英译 | 0.3333 / 0.3636（33） | 0 / 0（14） |

原中文基线的 SR/SP 均为 0。助手全文英译基线此前分别为 C04：0.3333 / 0.3243，C07：0.5714 / 0.0526。本次两个基线的 SR 相同，具体匹配句却不完全相同，因此不能把基线分数相同当作匹配准确性得到独立确认。[全部精度及对照](scoring/per_translation.csv) · [实际配对差值](reviewed_pairs.json)。

**例一：纯编号为什么引起 4/7→0。** C07 原文同一个操作，基线译为 `for oscillating dehydration`，改编号后译为 `and agitate for dehydration`。操作顺序及数字未变，译文其他位置也有少量措辞变化。四条参考在基线全部命中同一句，其相似度为 0.703775、0.704083、0.705268、0.705126；重译后对应最大值为 0.690573、0.691541、0.693076、0.692285。每条约 0.012–0.013 的变化跨过阈值，四个命中同时消失。

为区分编号与译文措辞，已在完整英文文本上执行一个离线交叉对照，全部重新解析、使用相同评分配置。两格来自实际 Qwen 回复，另两格仅改变行首编号，均明确标为事后诊断文本。

| 固定的英文措辞 | 原编号 | 改编号 |
|---|---|---|
| 基线那次 Qwen 的措辞 | SR=4/7，SP=1/19 | SR=4/7，SP=1/19 |
| 改编号那次 Qwen 的措辞 | SR=0，SP=0 | SR=0，SP=0 |

同一措辞下，改编号前后的编码输入逐字相同；改变的是另一轮翻译选择的表达。另做了仅翻译 T06 标签残留中文的离线对照，SR/SP 仍为 0，因为这段标签位于 `Protocol Steps` 之前，不进入当前步骤编码。这一定位针对本例成立，不证明所有翻译变动都只由这一短语决定。[交叉对照](mechanism_checks/factorial.csv) · [每条参考的阈值跨越](mechanism_checks/threshold_crossings.json)。

本例适合按不变性试验报告：内容不变的格式扰动理应不改变评价。CheckList 已系统提出这类行为测试方法，可作为实验设计依据；它并未提供可以直接消除本项目编码器阈值敏感性的现成修复。[Ribeiro 等，ACL 2020](https://aclanthology.org/2020.acl-main.442/)。

**例二：标题误分步能单独解决多少。** C04 的两个短标题以 `Wash` 开头，旧切分器将其视为祈使句；核染长标题又越过词数边界。它们都没有增加阈值命中，但把分母从 36 变成 39。因此 Qwen 基线的 SP=12/39，而助手英文基线只有一个标题误计，SP=12/37。

本轮实现了一个另列的、范围明确的结构过滤候选：只对有显式子编号、且标题本身没有绑定时间/温度/数值条件的父编号行，按标题角色排除。对 8 份实际译文重解析后，C04 四条件均排除 3 个标题，C07 均不变。C04 基线候选为 36 条、SP=12/36；删除候选为 30 条、SP=12/30。原 SR 均未变，删除不响应也仍在。

这说明标题过滤能够修正这批数据的分母，无法修复阶段错配或翻译措辞敏感性。候选尚未在更广泛结构、无子编号标题或父子均含实际操作的文档上确认，未升级为主切分器。[候选规则及事后计划](mechanism_checks/plan.json) · [原值与候选值并列](mechanism_checks/hierarchy.csv)。

**例三：删除与合并仍然揭示不同问题。** C04 删除后段 6 条操作，SR 仍为 3/9；生成端命中数仍为 12，所以 SP 从 12/39 升到 12/33。匹配证据显示，后段参考仍可命中前段操作；有的参考甚至匹配了不同试剂组合的相似句。删后 SP 上升是原公式分母与匹配集合共同作用的结果，不能解释为删步骤改善方案。

C07 合并后 SP 从 1/19 变成 2/18：既有分母减少，也有合并句新跨过阈值。四条参考的最佳匹配都转到合并句，该句本来只组合了两个操作；另一条生成操作仍有高于阈值的匹配。不能直接对原段落施加“一段只能命中一次”来修复，因为一段确实可能包含多个操作。需要先核对操作分解单位，再验证阶段和重复次数约束；原 SR/SP 仍应保留作为对照。

**翻译保真核查没有简单按数字字符清零。** 四份 C04 的全篇数字检查均提示多一个 `3`。来源定位表明它来自“三维”→“3D”，并非新增实验参数；全部操作单元数字与时间表达保持一致。另记录了标题压缩，例如“二抗全脑免疫标记”被简化成 `Secondary, far-red`；因此没有声称这些全文严格无损。T06 的四个中文字符保留为翻译不完整的局部负结果，同时保留真实步骤分数。

来源判断由当前助手进行，已经看到分数，不属于独立专家或盲法核查。一位专家 5 份开发＋15 份留出的预算没有增加，专家回执仍为 0。

**现有模块复用检查与下一步。** 仓库已有 `canonicalize_full_text`，本轮已实际应用于全部 8 份中文输入。C04、C07 的原文与改编号版本均没有得到相同的规范化文本；其英文动作/标题语法不能直接承担中文翻译前的编号规范化，不能仅接线后就宣称该问题已解决。[实际复用检查](existing_normalizer_reuse_check.json)。

下一步应保持问题与模块一一对应：先让翻译前的结构表示保留原文来源和交叉引用，同时把纯展示编号放在独立字段；验证纯编号变化是否产生完全相同的翻译输入。再对英文近义表达和操作实例作单独对照。固定一次译文并复用，可以保证同一表示的可重复计算；这本身不能证明不同忠实译文之间的评分具有不变性。标题候选可以继续离线扩展结构测试；阶段/重复实例模块需要已有分解记录及共享专家核查支持。

本批没有重新跑相同输入的随机重复，因此不更新旧稳定性统计；没有新增完整 CCE，因此不更新联合排名、Pareto 或重采样结论。时间归属、累计替换和分支账本仍沿用[上一轮四个真实时间案例](../REPORT_zh.md)，不将其算作本批的新提取结果。

可用于论文的方法学结论是：在这两份已暴露答案上，全文英译恢复了部分匹配，但全流程测试进一步揭示翻译措辞、切分粒度和操作实例对齐的独立影响。全部负结果已保存；当前证据不足以直接把“全文英译＋原句向量阈值”提升为已验证的主评价器。完整论文目标仍有定性 Cor 新试验、冻结后确认、跨评价器验证及专家/湿实验依赖待完成。[结果汇总](FINAL_SUMMARY.json) · [实际命令](COMMANDS.md)。
